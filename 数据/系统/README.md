# 机械状态

本目录只承载机器需要、但不定义认知内容的 JSON 数据。

| 目录 | 用途 | 是否可重建 |
|---|---|---|
| `ID登记/` | 稳定 ID 和已分配序号 | 通常不直接重建，避免身份漂移 |
| `临时候选/` | 尚未被用户认领的临时候选 | 可以丢弃，不等于正式对象 |
| `操作事件/` | 幂等键、操作结果和必要审计事件 | 视事件类型保留 |
| `索引/` | 全文或结构化检索索引 | 可以 |
| `缓存/` | 临时计算结果 | 可以 |
| `后台状态/` | 来源获取等后台任务状态 | 可以重新调度或人工处理 |

任何 JSON 都不得成为正式会话、闪念、认识或来源正文的唯一保存位置。
