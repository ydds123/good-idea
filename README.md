# Good Idea v0.16

Good Idea 是一个帮助松海保护思考现场、辨析闪念卡片并沉淀永久卡片的个人认知系统。

这一版只追求两个目标：**简洁**与**灵活**。

- 简洁：松海只需要表达、判断和确认，不必理解系统内部结构。
- 灵活：规则不依赖某个界面、Skill、应用或存储程序，可以根据真实使用调整。

## 当前结构

```text
松海与 Agent
     │
     ├── 依据 规则/ 协作
     │
     └── 把已经发生的事实保存到 数据/

规则/       产品语义、权责、协议与可调默认
数据/       人类可读的 Markdown 事实
验证/       场景推演、试运行方法与观察结果
文档/       产品定义与设计背景
.agents/    两个核心 Skill 的项目级入口
工具/       可选的执行能力实现，不是规则来源；删除后仍可按规则和模板手工完成
```

当前没有活动 Kernel，也没有应用层。现有技术原型保存在 Git 分支
`prototype/kernel-v0`，不参与当前运行规则。

## 权威边界

产品规则的权威边界和文件职责统一由 [`规则/README.md`](规则/README.md) 索引，并受 [`规则/系统宪法.md`](规则/系统宪法.md) 约束。本 README 只介绍项目结构，不维护对象、状态或协议的同义副本。

原始设计方案是重建时的设计输入，不是项目运行依赖；旧项目 `../good-idea` 只读保留，用于历史参考，不是本项目的地基。
