# Good Idea v0.16

Good Idea v0.16 是一个从零建立的规则优先个人认知系统。

它追求两个关键词：**简洁**与**灵活**。

- 简洁：用户只面对思考、判断和确认，不需要理解目录、状态机或命令。
- 灵活：规则独立于界面、消息渠道、Skill 和存储实现，可以在真实使用中调整。

旧项目 `../good-idea` 只作为历史数据和经验参考，不是本项目的代码、规则或目录基础。

## 层次

```text
用户
  ↓
Skill（可选薄入口）
  ↓
rules/   规则层：定义意义、权责与工作协议
  ↓
kernel/  执行支撑：执行确定性动作，不创造产品规则
  ↓
data/    数据层：保存已经发生的事实
```

当前不建设应用层。真实使用中反复出现并确实减少摩擦的组合，才会成为应用。

## 目录

- `rules/`：唯一规则层；每条规则只在一个文件中定义。
- `data/`：新数据与旧项目只读参考边界。
- `skills/`：可选的薄包装规范；当前没有正式 Skill。
- `kernel/`：确定性写入、状态转换、来源去重与召回支撑。
- `tests/`：规则场景与数据安全证据。

## 当前范围

核心只包含：

1. 原始思考会话；
2. 闪念；
3. 永久认识；
4. 外部来源；
5. 形成依据关系。

当前明确不做：Obsidian 布局、飞书应用、定时提醒、向量数据库、知识图谱、待办系统和通用关系管理。

## 开发

项目使用 Python 3.13 和标准库。

```bash
uv run python -m unittest discover -s tests -v
```

正式数据只能通过 `goodidea.service.GoodIdea` 写入；不要手工修改 `data/current/`。
