# 规则验证

本目录验证 `规则/` 是否真的能帮助用户和 Agent 协作，不以代码功能数量作为成功标准。

- `场景推演.md`：九个标准场景和补充边界场景的纸面推演。
- `Skill路由验收.md`：两个核心 Skill 的触发、排除和交接验收。
- `试运行协议.md`：直接对话试运行的保存和评估方法。
- `试运行记录/`：每次真实试运行的观察记录；捕捉类引用 `数据/记录/闪念/原始思考记录/` 中的完整对话，非捕捉类在试运行记录内保存完整可见对话。

验证材料可以发现规则缺口，但不能自行创造规则。需要修改规则时，先按 `规则/协作协议.md` 的规则演化协议处理，再更新这里的推演结论。
