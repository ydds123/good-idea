# 试运行观察记录

本目录保存试运行评测证据，正式对象仍保存在各自的 `数据/记录/` 目录。

- 捕捉类试运行：完整对话以 `数据/记录/闪念/原始思考记录/` 中的原始思考记录为准，本目录的记录只引用它并保存观察。
- 非捕捉类试运行：完整可见对话直接写在本目录的试运行记录中，不为辨析、永久卡片完善、召回或来源登记伪造原始思考记录。
- 试运行记录只是评测证据，不是正式认知对象。

文件以日期和主题命名，例如：

```text
2026-09-25-捕捉流程试运行.md
```

记录至少包括：

- 日期、类型和实际涉及的内容链接；
- 完整对话的位置：捕捉类引用原始思考记录，非捕捉类保存在本记录内；
- 松海原本要完成什么；
- 哪些步骤顺畅；
- 出现了哪些打断、纠正、噪声或多余步骤；
- 候选和召回是否忠实、相关；
- 最终产生了哪些对象，或是否零产出；
- 发现属于哪一类问题；
- 下一次只需要继续观察，还是已有重复证据需要修改规则。

捕捉类观察记录不得重写已经保存在会话文件中的完整对话。任何试运行都不得把一次体验直接升级为硬规则。
