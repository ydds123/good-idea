# 闪念内容表

> 补 base 数据库做不到的事：内容列。Bases 只认 frontmatter，正文只有 Dataview 读得到。
> 与 `闪念数据库.base` 分工：base 管状态/陈旧/节奏（行动），本表管内容扫读（阅读）。
> 本文件放 `闪念空间/查询/` 子目录——CLI 的 lint/verify 只扫空间根目录，此处是阅读层安全区。

```dataview
TABLE WITHOUT ID
  file.link AS "卡片",
  status AS "状态",
  substring(file.content, 0, 200) AS "内容摘要",
  created_at AS "创建时间"
FROM "闪念空间"
WHERE type = "闪念"
SORT created_at DESC
```
