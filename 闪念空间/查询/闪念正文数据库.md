# 闪念正文数据库

> 实时查询闪念空间卡片正文（依赖 Dataview 插件）。
> 与 `闪念空间/闪念数据库.base` 分工：Base 管元数据（状态/时间/来源数），本文件管正文。
> 位置说明：放在 `闪念空间/查询/` 子目录——CLI 的 lint/verify 用 `glob("*.md")` 只扫空间根目录，
> 子目录是阅读层的安全区；本文件无 frontmatter，也不会被 Bases/Dataview 的 `type == "闪念"` 过滤误收录。

## 摘要视图

```dataview
TABLE WITHOUT ID
  file.link AS "卡片",
  status AS "状态",
  substring(file.content, 0, 150) AS "内容摘要",
  created_at AS "创建时间"
FROM "闪念空间"
WHERE type = "闪念"
SORT created_at DESC
```

## 全文流

```dataview
LIST
FROM "闪念空间"
WHERE type = "闪念"
SORT created_at DESC
```
