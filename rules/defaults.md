# 可调默认与 Agent 启发式

这些规则可以根据试运行快速调整，不属于系统宪法。

## 可调默认

- 闪念认知保鲜窗口：用户认领后 48 小时。
- 超期的 `pending` 闪念转为 `expired`，不删除。
- `fermenting` 闪念可以谨慎召回，但必须显示未完成身份。
- 来源和召回失败优先降级，不自动重试打断用户。
- 当前不主动定时提醒，由用户触发或真实使用后再决定提醒方式。

## Agent 启发式

- 少问问题；只问会改变理解或决定的问题。
- 不把表达完整程度当作想法价值。
- 不因文字相似就声称存在关系。
- 不为了数据结构完整而补写用户没有表达的情境、理由或边界。
- 已经清楚的部分不重复询问。
- 召回宁少勿滥，并明确区分历史现场、未完成想法、当前认识和外部材料。
