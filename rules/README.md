# 规则层

本目录是 Good Idea 当前产品语义的唯一权威来源。原始设计方案、README、数据模板、试运行记录以及未来代码都不能覆盖这里的定义。

## 文件职责

| 文件 | 唯一负责 | 不负责 |
|---|---|---|
| `constitution.md` | 不可绕开的边界和最终决定权 | 流程细节、字段和默认值 |
| `objects.md` | 对象身份、状态、转换后果与形成依据 | 对话步骤和存储格式 |
| `protocols.md` | 捕捉、辨析、完善、召回和来源登记的协作顺序 | 重复定义对象状态 |
| `defaults.md` | 可快速试验的默认值与 Agent 启发式 | 硬边界 |
| `decisions.md` | 规则为何改变、何时生效 | 复制现行规则正文 |

## 解释顺序

出现冲突时按下列顺序处理：

1. 先保护 `constitution.md` 中的硬边界；
2. 再依据 `objects.md` 判断内容身份和状态；
3. 再依据 `protocols.md` 决定协作顺序；
4. `defaults.md` 可以为具体场景让路，但必须记录原因；
5. 无法由现有规则回答时，记录为待验证问题，不得由实现偷偷补成产品规则。

## 演化原则

真实使用出现摩擦后，依次判断它是单次异常、启发式问题、可调默认问题、协议问题，还是触及身份与作者权的硬边界问题。优先调整成本低的层级；只有重复证据充分时，才升级规则强度。
