# 任务交接：AGENTS.md 宪法修正——确立"共创前提"（用户焦点感知）

> 本文件是任务描述，由 2026-08-12 会话沉淀。接手者按本文件执行，不要扩大范围。

## 一、任务一句话

修改 `AGENTS.md`（系统宪法）共 **6 处**，并在 `decisions-v0.1.md` 追加一条决策记录，确立"用户焦点是 Agent 参与认知共创的输入起点"这一原则。

## 二、背景与动机

**触发场景**：用户在 Obsidian 闪念数据库的看板视图中选中一张闪念卡片，发起对话想把它加工成永久卡片。但 Agent 无法感知用户选中了哪张卡（Note Database 的选中状态是内存态，不落盘；Obsidian 只持久化"打开的文件"，且本次焦点在聊天视图）。共创因此断链——Agent 连用户在看什么都不知道，只能等用户把焦点翻译成语言。

**问题本质**：宪法只有"层"（内容层/协作层/执行层/阅读层/内部层/历史层）的静态描述，没有"流"（闪念 → 认知加工 → 永久卡片是跨阅读层→协作层→执行层的连续过程）的描述。**层与层之间没有接口条款**，焦点信息在起点（阅读层）就丢失。

**决策人判断**：修通道，不修定位。"对话组织者"的定位不变（判断权永远在用户，规则 5 已锁定）；缺的是 Agent 的输入通道——阅读层交互焦点 → 协作层 AI 的通道。

## 三、修改方案（共 6 处 + 1 项同步）

全部**只增补、不删除**既有承诺与规则表述。改动基于 AGENTS.md 当前 90 行版本（已确认干净，无未提交修改）。
