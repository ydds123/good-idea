# EAGLE 看图评分插件设计（v1 定稿）

> 定稿载体：本文档。过程记录（时间线）在待办卡「EAGLE评分过程数据插件」（TODO-20260827-d036ff0f）演化记录。本文档为梳理后的单一事实源，2026-08-27 定稿。

## 核心结论（价值主张）

**为想作图却缺思路的创作者，把 Eagle 里每次看图从"打个分"变成"带维度、带理由的分析"，沉淀成可检索的创作依据。**

后续所有功能取舍都对照这句话：不服务它的功能不做。

---

## 一、为什么：问题与背景

1. **创作困境**：GPT 作图缺乏思路——想作图，但不知道想要什么样的东西。希望通过看图多打开思路，作图时脑子里的东西起码会多一点。
2. **看图的价值定位**：看图 = 看别人怎么做 = 类似产品的竞品分析，最终目的是服务自身的创作需求，也是训练看图眼光的过程。
3. **现状断点**：Eagle 现在的评分是单一星级（1-5），只有一个最终结果；过程数据（为什么打这个分、是哪个维度、哪些点不错）全部丢失。看过的判断散失，无法复用——想要找某一系列的图时没有依据，也比单一评分更准确。

## 二、是什么：产品定义

### 场景边界

**在 Eagle 应用内看图时触发**——松海在 Eagle 里浏览图集、打开图片时评分；不是任意场景打开图（系统文件夹、外部看图器不算）。

### 用户旅程

1. 在 Eagle 内打开图
2. **打总体分**：给这张图打 1-5 星（Eagle 原生星级，人的直觉裁决）
3. **输入感受**：在右侧面板输入即时想法（自由文本，像说话一样）
4. **AI 拆分**：基于感受 + 总体分，映射到预设维度 → 每个维度的分数 + 理由 → 提炼"不错的点"清单
5. **结构化落盘**：维度评分 / 总体分 / 不错的点 / 原始输入，全部存进这张图的 annotation；维度打 tags
6. **检索复用**：作图缺思路时按维度/风格筛选、搜理由，找回来的每张图都带"当时为什么觉得好"的依据

## 三、怎么做：设计决策

### 1. 人机分工

- **人**：打总体分（直觉裁决）、输入感受
- **AI**：把感受拆到预设维度上、给维度分、写理由、提炼"不错的点"——是分析展开，不替人做总体判断
- 定位依据：用户是"缺思路的创作者"，拆分的方法论责任在系统不在用户

### 2. 维度体系（受控库 + 可配置）

- 拆分目标维度必须来自**用户预设的维度体系**——维度不统一，沉淀的数据没法做归类分析
- AI 只做映射不做自由发明；遇到覆盖不了的新维度，列候选等松海确认后再扩展
- 种子 9 维：

| 维度 | 它回答的问题 | 检索用途 |
|---|---|---|
| 风格 | 这图是什么风格/流派 | 按风格找图 |
| 主题/内容 | 图里画的是什么 | 按主题找图 |
| 构图 | 画面怎么组织 | 学构图找范例 |
| 光影 | 光怎么用 | 学光影找范例 |
| 色彩/配色 | 颜色怎么用 | 学配色找范例 |
| 氛围/情绪 | 图传达什么感觉 | 找有某种情绪的图 |
| 细节/质感 | 细节和材质处理 | 找细节处理范例 |
| 完成度/技术质量 | 技术层面好不好 | 筛高质量素材 |
| 创意/独特性 | 有没有令人意外的东西 | 找灵感 |

- **必须做成可配置的**：增删改在配置层完成，不硬编码；AI 只映射当前配置的维度

### 3. 分数语义

- 制式：1-5 分（与 Eagle 星级同制式；1-10 无意义）
- 总体分（人打，联动写回 Eagle 原生星级，原生排序筛选继续可用）+ 维度分（AI 拆）
- 每个维度分附理由；理由以自由文本为主，另提炼"不错的点"清单
- 原始输入留档（可回看当时的判断）

### 4. 数据落盘

- annotation：结构化存维度评分 / 总体分 / 不错的点 / 原始输入
- tags：维度标签（检索筛选入口）

## 四、实施路径（MVP 三步）

| 阶段 | 内容 |
|---|---|
| P0 | Inspector 插件 + 输入框 + 写 annotation（最小闭环） |
| P1 | 接入 AI SDK（自由文本 → 受控维度拆分） |
| P2 | 检索验证（tags 维度筛选 + annotation 全文搜索 + AI Search） |

## 五、可行性依据（2026-08-27 调研结论）

- **Inspector 插件**（Eagle 4.0 Beta 17+；本机 4.0.0 build 23 满足）：选中图片时右侧检查器面板出现插件 UI——应用内机制，天然匹配场景边界。Eagle 无全局快捷键 API，右键菜单可作辅助入口
- `eagle.item.getSelected()` 拿选中项；`item.add`/`item.modify` 写 annotation 与 tags
- **AI SDK 官方依赖插件**：统一模型配置中心（8 providers），支持 structured object generation——"输入感受 → 自动拆分"由它实现
- 检索：Eagle 原生搜索覆盖 annotation + AI Search 语义搜索 + tags 筛选
- 本机已有铺垫：eagle-prompt-annotation 油猴脚本（生图站 → eagle-annotation 元数据注入，同一条数据通路）；Hermes 侧 eagle skill（REST API 兜底/验证）
- 官方文档：developer.eagle.cool/plugin-api
