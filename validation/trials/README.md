# 试运行观察记录

本目录保存试运行评测证据，正式对象仍保存在各自的 `data/records/` 目录。

- 捕捉类试运行：完整对话以 `data/records/sessions/` 中的原始思考会话为准，本目录的记录只引用会话并保存观察。
- 非捕捉类试运行：完整可见对话直接写在本目录的试运行记录中，不为辨析、认识完善、召回或来源登记伪造 `SES-*`。
- `TRIAL-*` 只标识评测记录，不是第五类认知对象。

文件以试运行 ID 命名，例如：

```text
TRIAL-20260925-001.md
```

记录至少包括：

- 试运行 ID、类型和实际涉及的对象 ID；
- 完整对话的位置：捕捉类引用 `SES-*` 文件，非捕捉类保存在本记录内；
- 用户原本要完成什么；
- 哪些步骤顺畅；
- 出现了哪些打断、纠正、噪声或多余步骤；
- 候选和召回是否忠实、相关；
- 最终产生了哪些对象，或是否零产出；
- 发现属于哪一类问题；
- 下一次只需要继续观察，还是已有重复证据需要修改规则。

捕捉类观察记录不得重写已经保存在会话文件中的完整对话。任何试运行都不得把一次体验直接升级为硬规则。
