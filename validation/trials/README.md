# 试运行观察记录

本目录只保存评测观察。完整对话保存在 `data/records/sessions/`，正式对象保存在各自的 `data/records/` 目录。

文件建议以试运行日期和会话 ID 命名，例如：

```text
2026-09-25-SES-20260925-001.md
```

记录至少包括：

- 对应会话 ID 和试运行类型；
- 用户原本要完成什么；
- 哪些步骤顺畅；
- 出现了哪些打断、纠正、噪声或多余步骤；
- 候选和召回是否忠实、相关；
- 最终产生了哪些对象，或是否零产出；
- 发现属于哪一类问题；
- 下一次只需要继续观察，还是已有重复证据需要修改规则。

观察记录不得重写完整对话，也不得把一次体验直接升级为硬规则。
