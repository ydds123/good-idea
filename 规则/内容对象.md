# 对象契约

本文件定义四类正式内容对象、临时候选和形成依据。存储字段可以演化，但不得改变这些身份和状态含义。

## 原始思考会话

一次由用户明确发起、用于保护思考现场的连续对话。

- 保存用户与 Agent 的全部可见消息、先后顺序、时间以及用户带入的上下文。
- 正文以 Markdown 保存；摘要不能替代完整对话。
- 状态只有 `recording` 和 `closed`。
- `closed` 只表示本次连续记录窗口结束，不表示话题完成或观点成立。
- 旧会话可以续接，但续接事实必须可见。
- 会话边界由用户明确发起的捕捉现场决定，不由 Agent 根据语义实时拆分；对话中的分支先保存在同一现场，事后再判断是否形成多个认知单元。
- 一次会话允许不产生闪念或永久认识。

正式入口：用户明确要求开始捕捉或继续一个既有捕捉现场。

## 闪念候选

Agent 从当前表达和共同推理中整理出的临时草稿，不是正式内容对象。

- 可以存入临时机械状态，也可以只存在于当前对话。
- 不进入保鲜窗口、待辨析队列或默认召回。
- 用户可以接受、修改、合并、拆分或拒绝。
- 用户未认领时，不得因为对话结束而自动转正。
- 候选可以表达本次对话中新形成的理解，不必是用户原话的逐字摘录；但必须与完整对话区分，并让用户知道哪些内容经过了 Agent 组织或推导。

## 正式闪念

用户认领、愿意在认知仍新鲜时继续判断其价值的种子。它可以模糊、矛盾、不完整，也可以只是问题、异常或连接。

一条正式闪念至少应当能够唤起：它在说什么、为什么当时会注意到它，以及应从哪个形成现场继续思考。标题、核心内容、触发情境和形成依据是最小语义，不是要求用户填写的表单。

正式入口：用户认领一个完整可见的闪念候选。

| 状态 | 含义 | 默认召回后果 |
|---|---|---|
| `pending` | 尚未完成价值辨析 | 只在辨析或用户明确要求时出现 |
| `fermenting` | 用户认为值得保留，但当前缺少继续判断的条件 | 可谨慎出现，必须标明未完成 |
| `dismissed` | 用户判断当前不值得继续占用注意力 | 默认排除，历史仍可查 |
| `expired` | 在当前保鲜窗口内没有形成去向 | 默认排除，历史仍可查 |
| `formed` | 已参与形成一项永久认识 | 通过形成关系回看，不作为待处理项 |

转换要求：

- `pending` 可以进入 `fermenting`、`dismissed` 或 `formed`；达到可调保鲜期限且没有活跃讨论时可以进入 `expired`。
- `fermenting` 只需一段忠实于用户表达的自然语言备注，可以包含值得保留的原因、当前缺口或未来重启条件中的任意相关内容，不要求固定三字段。
- `dismissed`、`expired` 和 `fermenting` 都可以由用户重新激活为 `pending`，并开始新的保鲜窗口。
- 所有转换保留原内容、时间和决定来源。

## 永久认识

用户当前愿意接受、使用并允许未来调用的一项阶段性判断。

- 当前版本至少应能独立表达判断及其必要理由；只有确实影响适用范围时，才补充边界或不确定性。
- 生命周期状态只有 `active` 和 `retired`。
- `active` 默认可以参与召回；`retired` 默认排除，但历史可查。
- 修订不是生命周期状态。每次用户认领的修订形成一个新版本，旧版本继续保留，并记录生效时间和形成依据。
- 停用只改变当前生命周期状态，不删除任何版本。

正式入口：用户认领一个完整可见的永久认识候选，或认领对既有认识的修订候选。

## 外部来源

一个可稳定识别的外部内容身份，以及该身份下的一个或多个快照版本。

- 外部来源不代表用户赞同、理解或吸收了其内容。
- 同一身份只有一个来源对象；再次遇见时只增加原始引用、快照版本或使用记录。
- 用户明确说明是同一材料的新版本时，保留来源身份并追加快照。

| 状态 | 含义 |
|---|---|
| `pending_identity` | 已保存原始引用，但暂时不能可靠确定身份 |
| `pending_fetch` | 身份已确定，内容仍待获取 |
| `complete` | 当前快照获取完整 |
| `partial` | 只获得部分内容 |
| `failed` | 本次获取失败；来源身份和已有记录仍保留 |

正式入口：统一来源登记。解析器、Skill、应用、召回和旧数据适配器都不能旁路创建来源对象。

## 形成依据

形成依据说明永久认识实际上由哪些内容共同形成，可以指向：

- 原始思考会话；
- 正式闪念；
- 既有永久认识的具体版本；
- 外部来源的具体快照。

原始思考、闪念和既有认识即使成为形成依据，也不会因此变成外部来源。没有实际外部材料时，来源列表应保持为空。当前不持久化“相关”“支持”“冲突”“例证”等通用语义关系。
