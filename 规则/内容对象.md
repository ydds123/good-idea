# 对象契约

本文件定义四类正式内容对象、闪念生成过程记录、临时候选和解释性形成依据。存储字段可以演化，但不得改变这些身份和状态含义。正式 Markdown 中的状态统一使用中文。

## 有意思

松海明确认为值得留下、未来可能使用或继续判断，但尚未认领为正式闪念、永久认识，也不要求立即建立完整来源快照的内容。

- 可以保存工具、网站、仓库、模型、产品、提示词、方法素材、案例或参考方向。
- 至少保留“保存的是什么”；当时的保存动机、原始链接或产生情境真实存在时一并保留，不为完整而补写。
- 有意思不代表松海已经形成判断，也不等于外部来源的原文快照。
- 登记来源、形成闪念或形成永久认识后，有意思记录仍保留自身历史，并记录实际去向。

| 状态 | 含义 |
|---|---|
| `待处理` | 已保存，尚未决定是否进一步处理 |
| `已处理` | 已有明确处理结果，并记录实际去向 |
| `已放弃` | 当前不再值得继续占用注意力，历史仍保留 |

正式入口：松海明确表示某个内容“有意思”、值得留下以后再看，或明确要求保存为有意思。

## 闪念

闪念包含生成过程记录、临时候选和松海认领后的正式闪念。原始思考记录与正式闪念属于同一语义层级内部的不同阶段，不是并列的正式对象。

### 原始思考记录

一次由松海明确发起、用于保护正在发生的思考的连续对话。它保存在 `数据/记录/闪念/原始思考记录/`。

- 保存松海与 Agent 的全部可见消息、先后顺序、时间以及松海带入的上下文。
- 正文以 Markdown 保存；摘要不能替代完整对话。
- 状态只有 `记录中` 和 `已关闭`。
- `已关闭` 只表示本次连续记录窗口结束，不表示话题完成或观点成立。
- 旧记录可以续接，但续接事实必须可见。
- 记录边界由松海明确发起的捕捉行为决定，不由 Agent 根据语义实时拆分；对话中的分支先保存在同一份原始思考记录中，事后再判断是否形成多个认知单元。
- 一份原始思考记录允许不产生闪念或永久认识。

正式入口：松海明确要求开始捕捉或继续一个既有原始思考记录。

### 闪念候选

Agent 从当前表达和共同推理中整理出的临时草稿，不是正式内容对象。

- 可以只存在于当前对话，或在得到授权后保存为临时候选。
- 不进入保鲜窗口、待辨析队列或默认召回。
- 松海可以接受、修改、合并、拆分或拒绝。
- 松海未认领时，不得因为对话结束而自动转正。
- 候选可以表达本次对话中新形成的理解，不必是松海原话的逐字摘录；但必须与完整对话区分，并让松海知道哪些内容经过了 Agent 组织或推导。

### 正式闪念

松海认领、愿意在认知仍新鲜时继续判断其价值的种子。它可以模糊、矛盾、不完整，也可以只是问题、异常或连接。

一条正式闪念至少应当能够唤起：它在说什么、为什么当时会注意到它，以及应从哪份原始思考记录继续思考。标题、核心内容、触发情境和形成原因是最小语义，不是要求松海填写的表单。

正式入口：松海认领一个完整可见的闪念候选。

| 状态 | 含义 | 默认召回后果 |
|---|---|---|
| `待处理` | 尚未完成价值辨析 | 只在辨析或松海明确要求时出现 |
| `发酵中` | 松海认为值得保留，但当前缺少继续判断的条件 | 可谨慎出现，必须标明未完成 |
| `已放弃` | 松海判断当前不值得继续占用注意力 | 默认排除，历史仍可查 |
| `已失效` | 在当前保鲜窗口内没有形成去向 | 默认排除，历史仍可查 |
| `已形成认识` | 已参与形成一项永久认识 | 通过形成关系回看，不作为待处理项 |

转换要求：

- `待处理` 可以进入 `发酵中`、`已放弃` 或 `已形成认识`；达到可调保鲜期限且没有活跃讨论时可以进入 `已失效`。
- `发酵中` 只需一段忠实于松海表达的自然语言备注，可以包含值得保留的原因、当前缺口或未来重启条件中的任意相关内容，不要求固定三字段。
- `已放弃`、`已失效` 和 `发酵中` 都可以由松海重新激活为 `待处理`，并开始新的保鲜窗口。
- 历史迁入的待处理闪念保持 `待处理`；松海以后明确重新激活或开始辨析时，再建立新的保鲜窗口。
- 所有转换保留原内容、时间和决定来源。

## 永久认识

松海当前愿意接受、使用并允许未来调用的一项阶段性判断。

- 当前版本至少应能独立表达判断及其必要理由；只有确实影响适用范围时，才补充边界或不确定性。
- 生命周期状态只有 `有效` 和 `已停用`。
- `有效` 默认可以参与召回；`已停用` 默认排除，但历史可查。
- 修订不是生命周期状态。每次松海认领的修订形成一个新版本，旧版本继续保留，并记录生效时间和形成依据。
- 停用只改变当前生命周期状态，不删除任何版本。

正式入口：松海认领一个完整可见的永久认识候选，或认领对既有认识的修订候选。

## 外部来源

一个可稳定识别的外部内容身份，以及该身份下的一个或多个快照版本。

- 外部来源不代表松海赞同、理解或吸收了其内容。
- 同一身份只有一个来源对象；再次遇见时只增加原始引用、快照版本或使用记录。
- 松海明确说明是同一材料的新版本时，保留来源身份并追加快照。

| 状态 | 含义 |
|---|---|
| `待确认身份` | 已保存原始引用，但暂时不能可靠确定身份 |
| `待获取` | 身份已确定，内容仍待获取 |
| `完整` | 当前快照获取完整 |
| `部分获取` | 只获得部分内容 |
| `获取失败` | 本次获取失败；来源身份和已有记录仍保留 |

正式入口：统一来源登记。来源只能在松海明确要求保存外部材料时创建。

## 形成依据

形成依据说明永久认识实际上由哪些内容共同形成，可以指向：

- 原始思考记录；
- 正式闪念；
- 既有永久认识的具体版本；
- 外部来源的具体快照。

形成依据在正文中以自然语言说明“为什么有关联”，并在原因中附上对应文档链接。它不单独列出文件名、独立 ID 或机械依赖。没有真实关联理由时，不添加关联。
