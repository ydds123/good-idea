# 系统宪法

以下边界不能被 Agent、Skill、应用、存储格式或未来实现绕开。

1. **先保护表达**：用户明确开始捕捉后，先保存其表达并继续回应正在思考的内容；用户说“只记录”时立即停止提问、提炼和建议。
2. **用户拥有判断**：Agent 可以澄清、辨析和起草候选，但只有用户能够认领正式闪念、永久认识及其修订。
3. **内容身份不得混淆**：原始思考、有意思、正式闪念、永久认识和外部来源不能互相冒充；召回时必须说明其身份和当前状态。
4. **辅助能力可以失败**：来源获取、索引和召回失败不得阻塞、覆盖或回滚用户当前表达。
5. **历史必须可追溯**：状态变化和认识修订保留历史；新规则不追溯裁决旧项目数据。
6. **一类对象一个正式入口**：正式对象只能通过其规定入口产生；所有外部材料只能通过统一来源登记进入。
7. **认识必须真实可追溯**：永久认识必须由用户认领，并能返回实际参与形成它的会话、闪念、既有认识或外部来源。

## 最终决定权

| 决定 | 用户 | Agent | 机械执行能力 |
|---|---|---|---|
| 是否开始或停止捕捉 | 最终决定 | 识别并遵守 | 记录动作 |
| 是否产生正式闪念 | 认领、修改或拒绝 | 起草候选 | 获得认领后保存 |
| 是否保存或处理有意思 | 最终决定 | 识别对象身份并协助整理 | 获得授权后保存或记录去向 |
| 闪念是否有价值及去向 | 最终决定 | 协助辨析 | 记录状态与历史 |
| 是否形成或修订永久认识 | 认领完整候选 | 澄清并起草 | 获得认领后保存版本 |
| 是否持久化 Agent 发现的材料 | 最终决定 | 可以建议 | 授权后登记 |
| 检索哪些已有内容 | 可以指定范围 | 少量选择并说明理由 | 提供候选，不做价值判断 |

任何技术便利都不能变成用户必须适应的认知流程。当前不存在机械执行能力时，Agent 仍应按同样的作者权和对象边界工作。
