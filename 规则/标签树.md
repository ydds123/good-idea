# 标签树

标签用来表达「这份材料与什么相关」，作用是将来要提取时能按相关维度找到它——它是索引，不是分类。取值只来自本树。

设计参考 flomo（浮墨笔记）的标签思路：标签生来并不平等（有的做导航，有的做线索），层级主要用来分开这两种作用；一条材料可以挂多个标签；结构从使用中生长，不预先设计完整体系。

## 两类标签

- **导航标签**：按主线翻材料时会用的入口。少而稳，尽量停在一级；新增要克制，因为它是骨架。
- **线索标签**：从材料内容里提炼出来的相关线索。可以多、可以细，一条材料允许同时挂多个；不追求互斥穷尽。

## 层级

- 用 `一级/二级` 表示层级，最多两层。
- 一开始只有一级；同一主线下的材料确实分叉了再加第二层，不预先铺开。
- 引用时写完整路径。

## 生长与使用

1. 登记材料时先在本树查找匹配节点：命中就用节点名，一条材料可以挂多个（导航 + 线索）。
2. 没有匹配时，先在本树新增节点（单独提交），再写入记录；不要先写进记录再回填。
3. 新增要有意识：不按单篇材料的临时话题建节点，同一线索第二次、第三次出现才值得建。
4. 不记录能直接从来源、标题、日期读出的信息（载体是公众号、播客还是网页）；标签只表达这些字段看不出来的相关维度。
5. 不做无谓整理：只有出现同义重复、或某个导航标签长期不用时，才合并、改名或降级；线索标签多而不乱是正常的。
6. 命名用自然语言短语，不用 emoji 与特殊字符，英文单词之间用下划线。
