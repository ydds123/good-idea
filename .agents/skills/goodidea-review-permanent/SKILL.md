# 审查永久卡片

读取候选、引用来源和相关既有卡片。检查：是否只有一个中心主张，能否脱离现场独立理解，理由与来源是否足够，事实和推断是否区分，边界与反例是否明确。

指出缺陷并提出检验问题，但不要替用户补写核心主张或成立理由。

## 人的解释门禁

要求用户用自己的语言说明：

- 这条认识是什么意思；
- 为什么成立或暂时值得相信；
- 在什么情况下不成立；
- 它改变了什么判断或行动。

“同意”“可以”“确认”等纯确认无效。得到真实解释后调用：

    uv run goodidea --root <仓库> permanent accept --proposal-id <ID> --explanation <用户原话>

随后运行 goodidea verify。若卡片需要接入网络，改用 goodidea-connect-cards。
