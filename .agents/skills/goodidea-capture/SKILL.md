# 保护正在发生的认识

以尽可能小的干预保护正在生成的认知现场。

## 权威与加载

`../../../规则/` 是产品语义的唯一权威。本 Skill 只负责路由、加载、编排和停止；任何摘要与规则冲突时，以规则为准。

1. 始终读取 `../../../规则/系统宪法.md`。
2. 读取 `../../../规则/内容对象.md` 中与原始思考会话、候选、正式闪念和形成依据有关的内容。
3. 执行 `../../../规则/协作协议.md` 的捕捉协议。
4. 需要判断干预程度或是否建议捕捉时，读取 `../../../规则/默认规则.md`。
5. 只有实际涉及历史内容或外部材料时，才读取上下文召回或统一来源登记协议。
6. 发生写入时，读取 `../../../数据/README.md` 和对应模板。

## 编排

1. 先核对用户是否已明确进入捕捉。若没有，不创建任何捕捉数据；普通聊天中的可选建议按默认启发式处理。
2. 明确进入后，从触发消息开始完整执行捕捉协议，并持续按数据层约定保存可见对话。
3. 遇到“只记录”或同义表达，执行协议中的立即停止条件。
4. 到达自然结束点后，按协议判断是否提出候选；候选和正式对象的边界以对象契约为准。
5. 捕捉完成即停止。只有用户明确要求继续辨析、完善或维护既有认识时，才交接 `goodidea-distill`。

完成时确认：现场保存完整、窗口状态明确、未认领候选没有转正，也没有自动进入后续认知流程。
