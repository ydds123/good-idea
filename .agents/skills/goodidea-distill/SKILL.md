# 发展一个值得继续推敲的认识

判断并发展值得继续推敲的认识，或维护用户已经认领的永久卡片。

## 权威与加载

`../../../规则/` 是产品语义的唯一权威。本 Skill 只负责路由、加载、编排和停止；任何摘要与规则冲突时，以规则为准。

1. 始终读取 `../../../规则/系统宪法.md`。
2. 读取 `../../../规则/内容对象.md` 中与闪念卡片、永久卡片和形成依据有关的内容。
3. 辨析闪念卡片时执行闪念卡片辨析协议；形成或修订永久卡片时执行永久卡片完善协议；停用永久卡片时依据对象契约和松海最终决定处理。
4. 只有实际需要历史内容、行动或外部材料时，才读取对应的上下文召回、行动登记与处理或统一来源登记协议。
5. 需要对话干预或其他可调取舍时读取 `../../../规则/默认规则.md`。
6. 发生写入时，读取 `../../../数据/README.md` 和对应模板。

## 编排

1. 先识别松海是在处理闪念卡片、直接形成永久卡片、修订永久卡片还是停用永久卡片，并读取对应正式对象和必要形成依据。
2. 按所选协议推进，不把检索结果、外部材料或 Agent 推断冒充为松海当前判断。
3. 需要候选时完整展示并等待松海认领；写入、版本和生命周期变化按对象契约处理。
4. 松海作出决定后，执行闪念卡片辨析协议规定的同步动作，不在 Skill 中另设状态规则。
5. 当前意图完成即停止，不反向创建原始思考记录，也不自动开启新的捕捉。

## 退出与交接

- 新想法仍在生成且用户要保护现场时，退出并交给 `goodidea-capture`。
- 只是查询历史时，退出并直接执行上下文召回协议。
- 只是登记或处理行动时，退出并直接执行行动登记与处理协议。
- 只是保存外部材料时，退出并直接执行统一来源登记协议。
- 完成时确认用户保有最终判断，未认领候选没有转正，历史和对象身份没有被覆盖。
