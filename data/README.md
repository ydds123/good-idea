# 数据层

数据层只回答“已经保存了什么”，不定义对象应该意味着什么。

## 当前数据

`current/` 保存 v0.16 正式数据：

- `sessions/`：原始思考会话；
- `flashes/`：正式闪念；
- `insights/`：永久认识；
- `sources/`：外部来源及快照版本；
- `events/`：每次成功事务的不可变事件记录。

每个对象一个 UTF-8 JSON 文件。正式写入只能由 Kernel 完成。

## 旧项目参考

`legacy/reference.json` 只声明旧项目的位置和冻结提交。新系统不得在该目录复制旧数据，也不得调用旧业务代码。未来需要旧内容时，通过独立只读适配器按需读取。
