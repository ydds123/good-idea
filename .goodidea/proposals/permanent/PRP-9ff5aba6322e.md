# AI 产业价值流架构：八层一条链，治理横贯

**中心判断**：AI 产业是一条从能源到用户交互的八层价值流——每一层产出是下一层的投入；治理不是某一层，而是横贯全部层的结构。**构成即运转**：产业由什么构成，本身就是它如何运转。

**八层一条链**（自下而上）：

```
能源 → 芯片 → 算力网络 → 数据语料 → 基础模型 → 驾驭层 → 平台层 → 用户交互
```

- **能源层**：电网智能化、油气管道智能化、能源 AI 应用——AI 产业的物理底座
- **芯片层**：通用 GPU、新兴架构/端侧、EDA/互联、整机/封装制造——算力的硬件载体
- **算力网络层**：运营商算力网络、智算中心、算力调度与池化——算力的组织与交付
- **数据语料层**：语料基建、数据平台/向量库、标注工程、垂直语料/存储——智能的原料
- **基础模型层**：通用基座、大厂模型、多模态/世界模型、垂直大模型、端侧模型——智能能力本体
- **驾驭层**：上下文管理、工具调用、错误恢复/执行监控、中间软件栈/框架——把模型"偶尔的聪明"组织成稳定的执行能力（"模型会做一件事"与"把一件事真正做完"之间隔着很远）
- **平台层**：开发平台、互联协议（MCP）、技能市场/原生应用、交易机制（OPC/Token经济/RaaS）——供给与市场的衔接
- **用户交互层**：数字终端、具身机器人、行业应用、AIGC 内容创作——智能的消费形态（嵌入设备/做成软件/产出内容）

**治理横贯，不是某一层**：防护（模型/数据/内容/算力安全、可信沙箱）→ 约束（权限授权、分级监管、合规备案）→ 追责（责任链、事故还原）。智能体从生成内容走向执行行动，风险从"说错"走向"做错"——治理是智能体进入真实经济活动的入场前提，不是事后刹车。

**结构规律**：玩家密度梯度——越靠资源端越集中（芯片 40 家、寡头），越靠用户端越分散（应用 200+ 家、长尾）。上游是稀缺，下游是竞争。

**适用边界**：
- 这是 2026 年时间点的产业结构快照，层级随技术演化（端侧模型成熟、新形态出现）需要修订
- 具体企业的层级归属存在争议（如具身机器人横跨硬件/模型/场景），归属服务于分析目的而非绝对分类
- 架构覆盖产业供给结构与治理约束，不回答定价与交易的具体规则（Token 计价仍在形成中）
- 治理的"防护/约束/追责"是与八层正交的功能维度
