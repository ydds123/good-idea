# Good idea v0.1 决策冻结

冻结日期：2026-08-04

1. 从概念出发独立实现，不复用或迁移 `my-wiki`、`llm-wiki` 的代码、结构、数据和工作流。
2. 完整保留闪念、溯源、有意思、待办、永久五个空间；永久空间保留永久、母题、行动、索引四类卡片。
3. 溯源空间没有两个子目录。一份来源就是一份包含可编辑文献笔记区和受保护原文快照区的 Markdown 文件。
4. 输入附带链接时，想法进入闪念空间，正文 Markdown 快照和本地图片进入溯源空间，并双向链接。
5. 只有链接时，Agent 必须先阅读并提出内容相关的保存动机问题；用户回答后才持久化。放弃回答则零写入。
6. 默认只保存来源快照和待处理骨架，不自动生成作者观点或用户理解。
7. 永久卡片正式接纳前，用户必须用自己的语言重新解释；纯确认无效。
8. v0.1 七个核心 Skills 均需最小但真实可用；Skills 负责对话，CLI 负责确定性写入。
9. v0.1 仅供当前用户、macOS 本机使用；网页与微信公众号为首批来源，本地文件以后再做。
10. 每个成功原子事务自动创建 Git 提交；回滚使用非破坏性 revert。
11. Skills 位于项目内 `.agents/skills/`。
12. 真实验收包含 Karpathy gist、一篇公开公众号文章、用户本人一次保存动机和至少一张永久卡片的重新解释与接入。
13. 飞书概念说明 revision 30 与本文件共同构成 v0.1 基线；不回写飞书，执行期间不跟随新想法漂移。
